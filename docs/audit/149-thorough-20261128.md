# 149 — thorough-forced rerank (2.13.16)

Baseline 2.13.15 (`f098fbf`, 255 tests). Final **256/256** tests.

`lib/index.js` forces `rerank: true` and `deepCoverage: true` when
`intervention` is `thorough`, but the settings card still rendered an
editable Relevance rerank select showing the stored value (usually `false`).
The user could stage a value the provider ignores, and an invalid draft could
block Save.

The card now:

- derives `thorough` from the staged-effective tier;
- shows the rerank select as `true` and disables it under thorough;
- drops a staged `rerank` draft (and its `failedFields` entry) when entering
  thorough, through the same tier-draft helper that already handled official;
- points the disabled control at the intervention hint, which now appends
  “thorough forces relevance rerank and deep coverage; the rerank control has
  no effect”.

`deepCoverage` has no card control; the hint carries that information.

Tests: switching to thorough after staging rerank drops the draft, forces the
displayed value to true, disables the control and exposes `thoroughHint`.
