# 130 — 2026-11-28 round-4 audit fixes (2.12.0)

Baseline 2.11.0 (`4df4e11`, 225 tests). Three experts re-audited the domain,
presence, paging and Parallel work. Final: **225/225** tests, health 1/1,
npm 2.12.0, patches 32/32 + 33/33.

## Fixes

- **Presence gate reverted (P1).** Round 3 made `available()` return false for
  a confirmed missing key. The seam then returned its generic
  `WEB_PROVIDER_CONFIGURED_UNAVAILABLE` / “none registered” before our
  actionable key hint could run, and the second search lost the
  `CREDENTIAL_MISSING` taxonomy. The gate is removed; `/health` now carries
  `credentialMissing` from the last attempt while `available()` stays
  optimistic. The presence map and its test were removed with it.
- **Budget classification (P2).** Only a *timeout* caused by the shared or
  per-variant budget is exempt from breaker/health; a 429/500 on a clipped
  attempt still folds. `budgetClipped` now requires `timedOut` and includes
  `variantBudgetMs < configuredTimeoutMs - 10`, so a multi-query share cut no
  longer cools a backend that answered within its configured timeout.
- **SearXNG page 2.**
  - A caller abort during page 2 rethrows `WEB_ABORTED` instead of returning
    page 1 as a completed success.
  - Any page-2 failure (including 5xx) pauses pagination for 60 s, not just
    429/quota; the cooldown is cleared only by a successful extra page.
  - Multi-query and multi-instance paths still fetch one page.
- **Domain filters.** TLD regex accepts punycode
  (`(?:[a-z]{2,63}|xn--[a-z0-9-]{2,59})`), `*.` is stripped after URL parsing,
  and `domainFilterError` only fires when an enabled backend actually consumes
  domains (OpenAI/Anthropic). A DDG/SearXNG-only profile is no longer bricked
  by a field it cannot use; IDN domains work.
- **All-failed diagnostics.** Budget-skipped backends are counted separately
  (“N of M attempted; K skipped for budget”), telemetry renders `⏭budget`
  instead of a fake `✗0ms`, and breaker/health only see backends that ran.
- **Cache controls.** Card adds `cacheEnabled` (select) and `cacheTtl`
  (numeric, 0–86400 step 30), raising the editable set to 26 of 60; no-store is
  reachable without editing the profile.
- **Health.** Missing-key attempts now publish `credentialMissing` and stop
  being invisible as `reachable:null`; the breaker counters are preserved.
- **Parallel single-plan.** When internal multi-query is on, the primary
  variant carries `searchPlan {objective, queries}` and `parallel` (marked
  `handlesAllVariants`) runs once; later variants skip it. Other backends keep
  per-variant calls. Measured 3 calls → 1 for Parallel.
- **Privacy/docs.** `chmodSync` actually imported for cache/history dirs;
  README/cache header/JSDoc corrected (24s default, rank-major order, cache
  key components, paging conditions).
- **Tests:** domain IDN/consumer cases, Parallel plan, budget starvation,
  paging, cache controls.

## Verified fixed

Domain cache key; fail-loud only for consumers; cache no-store/perms; budget
deadline skips; Parallel plan; paging 429/abort; settings steps/attribution;
OpenAI/Anthropic/DeepSeek domain scoping.

## Still open

- Exa advanced MCP domain filter needs a recorded `tools/list` probe.
- Parallel plan failure/ranking trade-off is documented; no per-variant
  fallback if the single primary call fails.
- `credentialMissing` is a diagnostic; it does not disable a backend.
- Cache-hit `resultCount` uses pre-whitelist length (P3).
- Page-2 success clears the pause by design; a flapping page 2 can still cost
  one probe per minute.
