## 4. 未修（P2，已记录）

1. **多查询计数器放大**：`multiQuery` 每个变体各记一次 telemetry/history/breaker，2 后端 × 3 变体 = `6/6`，一次搜索可能触发阈值 3。需要按 backend id 去重或按搜索折叠。
2. **配置校验失败的后端从 telemetry 消失**：baseURL 校验在 promise 链外抛错，`backendsTotal` 少计。需要把校验移进链内或补 synthetic 失败条目。
3. **路由部分注册回滚**：`registerHistoryRoutes` 注册 A 成功、B 抛错时，A 的 disposer 未返回；需要各自回滚。
4. **结构化信任门的 HTTPS origin**：无 `connection` 服务时，`Host` 推导 scheme 恒为 http，https Origin 会被 403（当前 profile 挂载 connection，潜在）。
5. **设置卡未读取 `<id>ApiKeyEnv` 自定义值**：卡片仍读写默认 env ref（默认值下无差异）。
6. **`enabledBackends` 覆盖未在 UI 提示**：配置非空时开关会被 provider 忽略。
7. **可访问性**：输入无 `htmlFor`/`aria-*`，保存状态无 `aria-live`。
8. **npm 未发布**：`2.8.9` 仅存在于分支；`main` 未合并。
