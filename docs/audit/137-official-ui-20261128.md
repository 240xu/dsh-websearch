# 137 — 2026-11-28 official-tier card controls (2.13.6)

Baseline 2.13.5 (`11412c3`, 237 tests). Final **239/239** tests.

`resolveOptions` overrides several user-facing controls under
`intervention=official`: `numResults` (host cap), `rerank` (off),
`resultTelemetry` (off) and `resultHeader` (off). The card still rendered them
as live values, so a user could change a control that the provider ignored.

The card now computes the staged-effective intervention and disables those
four controls while official is selected; concurrency, cache, pagination and
the other shaping fields remain editable. The existing intervention hint
explains the official tier. This is presentational only: the server-side
precedence is unchanged, and a previously staged value keeps its staged state
(it is not silently discarded).

A gated control is disabled only while it holds no draft: a staged value stays
editable so it can be corrected or discarded, and `aria-invalid` marks the
numeric fields for the focus effect. The intervention hint now names the four
overridden fields and is wired via `aria-describedby`.

Tests: official disables untouched numResults/rerank/telemetry/resultHeader
and leaves concurrency editable; a staged numResults stays editable under
official and becomes focusable/invalid after a bad save.
